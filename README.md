# 📋 Formulario Interactivo con Vue.js

Aplicación web desarrollada con **Vue.js** y **Vite** como proyecto final de la Unidad V: JavaScript (Frameworks de JavaScript) de la asignatura **Programación Web 1**.

## 📌 Descripción

Esta aplicación permite registrar estudiantes mediante un formulario interactivo. Los datos ingresados se muestran dinámicamente en una tabla, permitiendo agregar múltiples registros sin recargar la página.

## 🎯 Funcionalidades

- Formulario con campos: Nombre, Apellido, Género y Carrera
- Visualización dinámica de registros en tabla
- Limpieza automática del formulario tras cada registro
- Diseño responsivo y organizado

## 🛠️ Tecnologías utilizadas

- [Vue.js 3](https://vuejs.org/)
- [Vite](https://vitejs.dev/)
- CSS personalizado

## 🌐 Demo en línea

🔗 [Ver aplicación desplegada](https://registro-estudiantes-vue.onrender.com)

## 🚀 Correr el proyecto localmente
```bash
# Instalar dependencias
npm install

# Correr en modo desarrollo
npm run dev

# Construir para producción
npm run build
```
